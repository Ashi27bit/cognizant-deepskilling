# Lab 4 - blogapp (Component Lifecycle)

## Objective
Create `blogapp` demonstrating `componentDidMount()` to fetch posts from a REST API and `componentDidCatch()` to handle errors during rendering.

## Steps
```bash
npx create-react-app blogapp
cd blogapp
```
Copy `Post.js`, `Posts.js`, and `App.js` into `src/`, then:
```bash
npm start
```

Data source used: https://jsonplaceholder.typicode.com/posts
