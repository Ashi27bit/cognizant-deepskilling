# Lab 1 - My First React App

## Objective
Create a React app named `myfirstreact` that prints "welcome to the first session of React" as a heading.

## Steps
```bash
npx create-react-app myfirstreact
cd myfirstreact
```
Replace the contents of `src/App.js` with the file in this folder, then run:
```bash
npm start
```
Open `http://localhost:3000` in your browser.
