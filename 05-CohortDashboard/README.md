# Lab 5 - Cohort Dashboard (CSS Modules & Inline Styles)

## Objective
Style the CohortDetails component using a CSS Module (`.box` class, `dt` tag styling) and conditional inline styles (green for "ongoing", blue otherwise).

## Steps
```bash
npx create-react-app CohortDashboard
cd CohortDashboard
```
Copy `Cohort.js`, `CohortDetails.module.css`, `CohortDetails.js`, and `App.js` into `src/`, then:
```bash
npm start
```
