# Lab 8 - counterapp (React State)

## Objective
Create `counterapp` with a `CountPeople` component tracking entry/exit counts in state, with `UpdateEntry()` and `UpdateExit()` methods triggered by Login/Exit buttons.

## Steps
```bash
npx create-react-app counterapp
cd counterapp
```
Copy `CountPeople.js` and `App.js` into `src/`, then:
```bash
npm start
```
