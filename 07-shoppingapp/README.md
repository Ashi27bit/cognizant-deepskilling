# Lab 7 - shoppingapp (Props)

## Objective
Create `shoppingapp` with class components `Cart` (Itemname, Price props) and `OnlineShopping` which holds an array of 5 Cart items and renders them via props.

## Steps
```bash
npx create-react-app shoppingapp
cd shoppingapp
```
Copy `Cart.js`, `OnlineShopping.js`, `App.js` into `src/`, then:
```bash
npm start
```
