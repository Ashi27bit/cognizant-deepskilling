# Lab 12 - ticketbookingapp (Conditional Rendering)

## Objective
Guest users see the flight list; logged in users see the booking page. Login/Logout buttons toggle between the two views.

## Steps
```bash
npx create-react-app ticketbookingapp
cd ticketbookingapp
```
Copy `GuestPage.js`, `UserPage.js`, and `App.js` into `src/`, then:
```bash
npm start
```
