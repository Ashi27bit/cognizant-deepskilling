# Lab 11 - eventexamplesapp (React Events)

## Objective
Demonstrate event handling: Increment/Decrement buttons (with the increment calling multiple methods), a "Say Welcome" button that passes an argument, a synthetic `onClick` event, and a `CurrencyConvertor` component converting INR to EUR on submit.

## Steps
```bash
npx create-react-app eventexamplesapp
cd eventexamplesapp
```
Copy `Counter.js`, `CurrencyConvertor.js`, and `App.js` into `src/`, then:
```bash
npm start
```
