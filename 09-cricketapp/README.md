# Lab 9 - cricketapp (ES6 Features)

## Objective
Create `cricketapp` demonstrating ES6 `map()`, arrow functions, and destructuring, with two components (`ListofPlayers`, `IndianPlayers`) toggled via a `flag` variable.

## Steps
```bash
npx create-react-app cricketapp
cd cricketapp
```
Copy `ListofPlayers.js`, `IndianPlayers.js`, and `App.js` into `src/`. Toggle the `flag` constant in `App.js` between `true`/`false` to switch views, then:
```bash
npm start
```
