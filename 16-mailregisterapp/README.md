# Lab 16 - mailregisterapp (React Forms Validation)

## Objective
Create `mailregisterapp` with a `register.js` form validating Name (>=5 chars), Email (must contain `@` and `.`), and Password (>=8 chars) via event handlers on submit.

## Steps
```bash
npx create-react-app mailregisterapp
cd mailregisterapp
```
Copy `register.js` and `App.js` into `src/`, then:
```bash
npm start
```
