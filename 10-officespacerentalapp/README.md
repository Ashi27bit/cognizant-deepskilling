# Lab 10 - officespacerentalapp (JSX)

## Objective
Create `officespacerentalapp` using JSX to render a heading, an image attribute, an office details object, and a list of offices — coloring rent red if below 60000, green if above.

## Steps
```bash
npx create-react-app officespacerentalapp
cd officespacerentalapp
```
Copy `App.js` into `src/`, then:
```bash
npm start
```
