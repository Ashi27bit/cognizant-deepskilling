# Lab 15 - ticketraisingapp (React Forms)

## Objective
Create `ticketraisingapp` with a `ComplaintRegister` component: a textbox for employee name, a textarea for the complaint, and a `handleSubmit` that generates and alerts a reference number.

## Steps
```bash
npx create-react-app ticketraisingapp
cd ticketraisingapp
```
Copy `ComplaintRegister.js` and `App.js` into `src/`, then:
```bash
npm start
```
