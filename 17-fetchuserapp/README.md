# Lab 17 - fetchuserapp (Consuming REST APIs)

## Objective
Create `fetchuserapp` with a `Getuser` component that fetches a random user from `https://randomuser.me/api/` in `componentDidMount()` and displays title, first name, last name, and image.

## Steps
```bash
npx create-react-app fetchuserapp
cd fetchuserapp
```
Copy `Getuser.js` and `App.js` into `src/`, then:
```bash
npm start
```
