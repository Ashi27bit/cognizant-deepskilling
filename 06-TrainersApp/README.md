# Lab 6 - TrainersApp (React Router)

## Objective
Build a SPA listing Cognizant Academy trainers with navigation via React Router: `/` redirects to Home, `/trainers` shows the list, `/trainers/:id` shows detail via `useParams`.

## Steps
```bash
npx create-react-app TrainersApp
cd TrainersApp
npm install react-router-dom
```
Copy all files from this folder into `src/`, then:
```bash
npm start
```
