# Lab 3 - scorecalculatorapp (Function Component + Styling)

## Objective
Create `scorecalculatorapp` with a function component `CalculateScore` that accepts Name, School, Total, and Goal as props, calculates average score, and displays it with CSS styling.

## Steps
```bash
npx create-react-app scorecalculatorapp
cd scorecalculatorapp
mkdir src/Components src/Stylesheets
```
Copy the files from this folder into their respective locations, then:
```bash
npm start
```
