# Lab 13 - bloggerapp (Conditional Rendering Variations)

## Objective
Create `bloggerapp` with BookDetails, BlogDetails, and CourseDetails components, each demonstrating a different conditional rendering technique (early return, ternary, `&&` operator, element variables).

## Steps
```bash
npx create-react-app bloggerapp
cd bloggerapp
```
Copy all files into `src/`, then:
```bash
npm start
```
